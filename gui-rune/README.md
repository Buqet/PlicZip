# PlicZip Rune Preview

Экспериментальная графическая оболочка PlicZip на Rune. Пакет развивается параллельно текущему `pliczip-gui` на egui и не заменяет его.

## Уже работает

- Открытие native `.plz`-архива через системный диалог выбора файла.
- Резервная загрузка по введённому пути, если системный диалог недоступен; Enter запускает загрузку.
- Отображение реальных записей из индекса архива: имя, тип и размер.
- Живой поиск по имени и пути записи без изменения исходного индекса.
- Сортировка по колонкам и multi-select через `rune-kit::Table`.
- Извлечение всего незашифрованного архива в указанную папку; существующие файлы пропускаются, а пути обрабатываются безопасным extraction API ядра.
- Некорректный файл или неподдерживаемая операция показывают статус в окне; при ошибке ранее открытый архив остаётся на экране.

Создание, выбор отдельных записей для извлечения и парольный ввод ещё не перенесены; зашифрованные архивы пока не открываются в Rune preview. Основная egui-оболочка остаётся рабочим приложением с полным набором операций.

## Запуск

```bash
cargo run -p pliczip-gui-rune
```

Проверки:

```bash
cargo check -p pliczip-gui-rune
cargo test -p pliczip-gui-rune
```

Rune является pre-release Git-зависимостью. Версия зафиксирована через `rev` в `Cargo.toml`. Для системного диалога включена Rune feature `native-file-dialog`. В корневом workspace также лежат необходимые vendor-патчи upstream Rune для `parley_engine`, `winit` и `sctk-adwaita`; без них pinned commit не собирается как внешняя зависимость.
