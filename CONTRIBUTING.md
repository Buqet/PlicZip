# Как внести вклад в PlicZip

Спасибо за интерес! Ниже — короткие правила.

## Сборка и проверка

Нужен Rust ≥ 1.82 (MSRV).

```sh
cargo build                                        # CLI + GUI
cargo test -p pliczip                              # тесты библиотеки и CLI
cargo clippy -p pliczip --all-targets -- -D warnings
cargo fmt --all
```

CI проверяет форматирование, clippy, тесты на Linux/Windows/macOS, сборку на MSRV и уязвимости зависимостей (`cargo audit`). PR с красным CI не сливаются.

## Правила

- Одна задача — один PR. Опишите *что* и *зачем*, приложите шаги проверки.
- **Формат `.plz` — публичный контракт.** Любое изменение раскладки байтов требует повышения версии формата и сохранения чтения старых архивов. Описание формата — в `src/format.rs`.
- Код, разбирающий архив, не должен паниковать на любых входных данных: никаких `unwrap()`/индексации без проверки длины — возвращайте ошибку.
- Криптографию не изобретаем: только проверенные крейты RustCrypto.
- Новые зависимости — только на чистом Rust (проект собирается без C-тулчейна).
- Добавляйте тесты на исправленный баг или новую функцию.
- Изменения, заметные пользователю, — строкой в `CHANGELOG.md` (раздел *Unreleased*).
