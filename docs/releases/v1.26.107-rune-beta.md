# PlicZip v1.26.107-rune-beta

## Русский

Экспериментальный beta/pre-release для проверки нового GUI на Rune.

В состав Windows Setup входит `PlicZip.exe` на Rune вместо стабильного egui GUI. Это первый preview-срез: таблица файлов архива, сортировка по колонкам, multi-select и базовая визуальная оболочка. Архивные операции и часть функций PlicZip пока ещё переносятся поэтапно.

Для обычной работы используйте стабильный релиз `v1.26.106`. Rune находится в pre-release, поэтому этот выпуск предназначен для тестирования и обратной связи.

## English

Experimental beta/pre-release for testing the new Rune GUI.

The Windows Setup includes the Rune-based `PlicZip.exe` instead of the stable egui GUI. This first preview slice contains the archive file table, column sorting, multi-select, and the basic visual shell. Archive operations and some PlicZip features are still being migrated incrementally.

For normal use, please use the stable `v1.26.106` release. Rune is still pre-release, so this build is intended for testing and feedback.
