# v1.26.112-rune-beta

## Русский

- Rune GUI сортирует архивные записи через лениво создаваемый вектор индексов. Исходный порядок и стабильные ID записей сохраняются, а фильтр продолжает следовать текущей сортировке.
- В синтетическом микробенчмарке на 250 тыс. записей сортировка по размеру заняла примерно на 25,2% меньше времени, сортировка по имени — примерно на 4,5% больше. Это замер сортировки данных, а не полного GUI; результат зависит от набора и порядка записей.

Это beta-релиз Rune GUI для проверки пользователем.

## English

- The Rune GUI sorts archive rows through a lazily allocated index vector. Original entry order and stable IDs are preserved, and filtering follows the active sort order.
- In a synthetic microbenchmark with 250,000 entries, size sorting took about 25.2% less time, while name sorting took about 4.5% more. This measures data sorting, not the full GUI; results depend on the dataset and its ordering.

This is a beta release of the Rune GUI for user testing.
