# PlicZip v1.26.108-rune-beta

## Русский

Экспериментальный pre-release для тестирования Rune GUI.

В Rune preview добавлены загрузка `.plz` через системный диалог или вручную введённый путь, просмотр записей реального индекса архива, сортировка, мультивыбор и живой фильтр по имени/пути. Также можно распаковать весь незашифрованный архив в указанную папку. Папка назначения предлагается автоматически; существующие файлы пропускаются.

Создание архивов, выборочное извлечение и ввод пароля пока не поддерживаются; зашифрованные архивы в Rune preview не открываются. Rune GUI остаётся экспериментальным. Для обычной работы используйте стабильный релиз `v1.26.106`.

## English

Experimental pre-release for testing the Rune GUI.

Rune preview now supports opening `.plz` archives through the system file dialog or a manually entered path, viewing the real archive index, sorting, multi-select, and live filtering by entry name/path. It can also extract an entire unencrypted archive to a selected folder. A destination is suggested automatically, and existing files are skipped.

Archive creation, selective extraction, and password entry are not supported yet; encrypted archives cannot be opened in the Rune preview. The Rune GUI remains experimental. For normal use, please use the stable `v1.26.106` release.
